# 📁 Pattern Categories

## 🔠 Letters Patterns

Contains alphabet star patterns from:

```text
A → Z
```

📌 Example Files:

- `A.java`
- `M.java`
- `Z.java`

### 🔺 Example A Pattern

```text
              *               
            *   *             
          *       *           
        * * * * * * *         
      *               *       
    *                   *     
  *                       *   
```
