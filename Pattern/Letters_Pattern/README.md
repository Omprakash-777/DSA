# 📌 About Project

This repository contains Java programs for printing **English Alphabet Patterns** using stars (`*`).

Each Java file represents one alphabet letter pattern.

✅ Easy to understand  
✅ Beginner friendly  
✅ Great for logic building  
✅ Perfect for pattern practice
