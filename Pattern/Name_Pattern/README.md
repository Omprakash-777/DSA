# 📌 About The Project

This project prints **custom names and words** using star (`*`) patterns in Java.

The patterns are built using:

- 🔁 Nested Loops
- ❓ Conditional Statements
- 🧠 Matrix Logic
- ✨ Creative Pattern Design

Perfect for:

✅ Beginners
✅ Java Practice  
✅ Pattern Programming
